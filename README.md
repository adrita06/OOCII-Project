Project Overview:
My project is a salad counter management system that assists users in ordering salads while keeping track of the calories and price of the salad purchased.
The system is designed to make the ordering process smooth and efficient. It allows customers to choose ingredients based on their preferences while being health-conscious and budget-aware.

Project Details:
The system offers only a customer interface.
Customers can view the pre-defined menu and order a salad from there. The menu displays the salad name, description, ingredients, total calories, and price of each salad. Customers also have the option to add extra ingredients, with each addition updating the total calories and price in real time.
Alternatively, they can create a fully customized salad from scratch. As they add ingredients, the updated calorie count and price are shown for each addition.
Once a salad is completed, it will be added to the cart. Customers can then choose to:
● Add another salad,
● View the cart, or
● Cancel any salad already added to the cart.
When viewing the cart, customers will see:
● A list of all salads added,
● The ingredients in each salad,
● The calorie count and price of each salad,
● Finally, the total price and total calories for the entire order are given.
If they wish to remove a salad, they can do so by entering the salad number (as shown in the cart), and it will be removed.
They can also cancel the entire order if needed.
After confirming the order, a receipt will be generated, and loyalty points will be awarded based on the total price. If the order exceeds 500 Taka, the customer will receive a discount based on their accumulated points.

System Architecture:
● Frontend: Simple interface to facilitate customer order.
● Backend: Logic handling for order placement, calorie calculations, price calculation, loyalty points calculation, discount applied.
● Storage: Salad, ingredient, and customer data are stored using file-based systems.

Features:
● Add to Cart from Pre-defined Menu: Customers can select salads from a curated menu and add them directly to their cart.
● Add Customized Salad to Cart: Users can build their salad by choosing ingredients, with real-time updates to calorie count and price.
● View Cart: Customers can view all added salads, see the ingredients in each, and check the total calories and price.
● Remove from Cart: Specific salads can be removed from the cart by entering the salad number.
● Cancel Entire Order: Users have the option to cancel the full order before confirming.
● Confirm Order: Finalizes the order and generates a detailed receipt.
● Loyalty Points System: Loyalty points are awarded based on the total price of each confirmed order.
● Discounts on Large Orders: For orders above 500 Taka, discounts are applied based on the customer’s accumulated loyalty points.

Technology used:
● Java (IntelliJ IDEA)
● Git & GitHub

Justification:
The project directly aligns with the theme "Savour the Flavour of Health" by combining flavorful salad choices with a focus on well-being and nutrition. It enables users to enjoy customizable, healthy meals while being informed about the calories of the salad.
By keeping only health-conscious ingredients available, we are encouraging customers towards a more mindful and balanced diet. At the same time, the freedom to add desired seasonings and dressings to their salad allows customers not to compromise on the taste - which proves that healthy eating doesn’t have to be bland.
